# BDD

Сценарий — три наблюдаемые строки.

```
Given <контекст>
When <действие>
Then <результат, который можно увидеть или проверить>
```

В CLI несколько сценариев передают одним флагом `--acceptance` и разделяют `|`.

Годный Then называет состояние, которое проверяют. «Работает хорошо» не годится. «В store есть external_id ABC-2» годится.

До статуса `ready` нужен счастливый путь и один путь отказа или пустого входа. Для технического среза это говорят в названии, а не прячут вызов функции внутри Then.

QA переводит в `done` только когда у каждой строки есть улика: имя проверки, вывод команды или явная человеческая отметка в описании. Отсутствие улики оставляет карточку в `review`.
