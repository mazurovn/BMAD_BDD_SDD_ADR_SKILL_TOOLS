# Команда

Команда собрана так, чтобы сложный продукт не схлопывался в одного «архитектора всего». У каждой роли одна модель мышления, статы от 0 до 5 и правило остановки. 5 значит «это оптимизирует». 0 значит «это оптимизировать нельзя». Статы — приоритеты, не замер скорости.

| Роль | Модель | Оптимизирует | Не трогает |
|---|---|---|---|
| Analyst | сначала расхождение вариантов, потом схождение | ясность проблемы | выбор технологии |
| PO | работа, которую человек нанимает продукт сделать | исход одной фразой | часы вместо points |
| BMAD lead | ворота фаз | порядок анализ → план → проект → сборка | закрытие карточек |
| Business architect | способности и потоки ценности | граница продукта | классы и библиотеки |
| Enterprise architect | владение данными и долгие решения | граница систем и команд | внутренности сервиса на спринт |
| Solution architect | контракт, по которому строят другие | интерфейс, данные, отказ | подмена разработчика |
| Architecture chair | маршрутизация трёх уровней | кто говорит сейчас | слияние слоёв |
| ADR keeper | односторонняя и двусторонняя дверь | дорогой выбор записан | удаление старого ADR |
| SDD author | спецификация отклоняет лишний дифф | якорь до кода | реализация до границ |
| BDD author | примеры бьют формулировку | наблюдаемый Then | шаги реализации внутри Then |
| Sysl modeler | поведение как вызовы | файл важнее картинки | состав системы |
| CALM modeler | состав как узлы | стабильный id | поведение эндпоинта |
| SM | поток, не загрузка людей | лимит незавершённого | смена принятого ADR |
| Dev | одна история | движение до review | статус done |
| Lazy senior | лестница наименьшего кода | код, который не написан | срез безопасности |
| QA | попытка опровергнуть Then | улика | закрытие без неё |
| Integrator | файл или честный отказ API | сохранённый внешний ключ | слово «синхронизировано» без pull |
| Skill creator | повтор процедуры | новый скилл с границами | копирование чужого дерева |
| Researcher | утверждение только с проверкой | неизвестное названо неизвестным | выдуманное имя файла |
| Writer | команда из `--help` | документ совпадает с CLI | описание несуществующей команды |
| Release | зелёный audit | несданный метод не называется готовым | принятие плана за прогон |

Полные правила, которыми они пользуются, лежат на странице Rules. Файлы ролей лежат в `agents/`.
